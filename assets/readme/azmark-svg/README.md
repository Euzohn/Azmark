# Azmark 行迹 · Logo 资产

Azmark(行迹)的矢量标识套装。核心符号把字母 **A** 与 **Z** 连成一体:
**A** 是一座圆角山峰(起点、方向、向上延伸),它的右腿顺势化为 **Z** 的上横线,
Z 走完最后一个转折后,落到右下角的**陶土橙圆点** —— 终点 / 抵达,也就是「行迹」本身。

圆角笔画、一笔连贯、无渐变、无阴影、纯几何,单色下依然成立。

## 文件

| 文件 | 用途 |
| --- | --- |
| `azmark-symbol.svg` | 主符号(石墨 + 陶土橙),任一场景的基准图形 |
| `azmark-symbol-black.svg` | 纯黑单色符号 |
| `azmark-symbol-white.svg` | 纯白单色符号(深底) |
| `azmark-horizontal.svg` | 横版组合:符号 + `AZMARK` 字标 + 标语 |
| `azmark-horizontal-dark.svg` | 横版组合 · 深底(纸白 + 浅苔藓绿) |
| `azmark-vertical.svg` | 竖版组合:符号 + 字标 + 标语 + 品牌短句 |
| `azmark-app-icon.svg` | 应用图标 · 深底(石墨圆角方 + 纸白符号) |
| `azmark-app-icon-light.svg` | 应用图标 · 浅底(纸白圆角方 + 石墨符号) |

## 色彩

| 名称 | Hex | 用途 |
| --- | --- | --- |
| Graphite 石墨 | `#252822` | 主线条 / 深底 |
| Paper 纸白 | `#F5F1E8` | 底色 / 深底上的线条 |
| Terracotta 陶土 | `#C66B4E` | 终点圆点(点缀,唯一强调色) |
| Moss 苔藓 | `#78816A` | 副标语 / 品牌辅助色 |

单色版仅用 `#000000` / `#FFFFFF`,保证在刻字、烫印、丝印等场景可用。

## 使用规范

- **清晰空间**:四周留出至少等于「符号高度 × 0.25」的空白,勿在符号旁紧贴文字或其它图形。
- **最小尺寸**:符号单独使用时 ≥ 16 px;横版组合 ≥ 96 px 宽;应用图标 ≥ 32 px。
- **不得改动**:保持比例,勿拉伸、勿旋转、勿加描边/投影/渐变;唯一强调色是陶土橙圆点。
- **深底**:在深色背景上使用 `-dark` / `-white` 版本,勿直接把浅底版本放到深色上。

## 生产提示

组合版本里的 `AZMARK` 字标与标语目前是 `<text>` 元素(字体栈
`Inter, Avenir, Helvetica, Arial`)以方便编辑与跨平台预览。
**正式对外发布前,建议把字标转为轮廓路径(outline)**,以避免不同环境字体缺失或回退导致的宽度变化。
符号本身是纯路径,不受字体影响。
